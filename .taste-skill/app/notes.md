# 週単位の宿題アプリ — デザイン記録

- 対象: 先生が週の課題を決め、生徒が日ごとの計画と実績を記録し、先生が日単位で見守る1対1の学習ノート。
- 読み手: 生徒は毎日スマートフォンから短く記録。先生は週に数回、スマートフォンまたはPCで課題を編集して確認。
- 画面の問い（生徒）: 今日の目標を決め、予定に対してどこまで進んだか。
- 画面の問い（先生）: 一週間の目標と実績にずれがある日はどこか。
- 実データ: 週の開始日、先生の課題（最大20件）、7日分の自由記述計画と実績、達成状態、確認コメントとスタンプ、計画変更履歴、課題単位の提出写真。
- マグニチュード: 週は常に7日。登録直後は0課題・0計画をそのまま表示し、架空の達成数や比較値を追加しない。
- 主要操作: 生徒は曜日を選んで計画・実績を保存。先生は週の宿題を保存し、日ごとの記録に確認を返す。
- 維持する操作: 月をまたぐ月曜始まりの週切替、当日と前日の実績編集、過去の日別記録の閲覧。
- 独自の顔: 印刷された週間ノートの見開き。平日の区切りを同じ幅で並べ、計画と実績の「歩幅」を日ごとに読み取る。
- サイン要素: 7日レーン。選択日を青緑の下線、計画済み/達成数を短い実数で示す。操作できる日付ボタンがそのまま週の進捗表になる。
- 色・型: editorial-greeting / 端末内蔵の日本語角ゴシック + 明朝。Google Fontsへのビルド時通信を避けるため、Windows・iOS・Androidの日本語標準書体へフォールバック。低彩度の紙色 #F5F4EE、インク #202C29、青緑 #1B6E66。青緑はブランドの週マーク、選択日、主操作に限定。朱色は未達など注意状態だけ。
- レイアウト算術: 最大幅1100px、中央配置、左右の余白は各20px以上。7日列は等幅・すき間なしで 7 × 1/7 = 1100px。スマートフォンは左右10px余白、日付幅約47px（幅375px時）を維持。
- ホームの4つの汎用数値タイルは、実在しない指標を作らず、学習アプリ固有の7日レーンに置換。外枠やカード数を増やさず、週の問いを最初に見せるための意図的な画面構成変更。
- 課題一覧、計画、実績、確認、写真提出、旧履歴を含むデータ操作は従来どおり実アカウントのAPIデータから描画。デモ用の生徒名・課題・数値は追加しない。
