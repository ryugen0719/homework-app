# 宿題ノート・4週間試用シート

実際の利用時間と記録の続きやすさを確かめるための記入用シートです。アプリに機能や通知を追加せず、先生と生徒の利用記録だけで目標を確認します。

## 試用の前に

- 試用期間：　　　　年　　月　　日 〜　　　　年　　月　　日
- 使用端末・ブラウザー：
- 生徒が初めて使う日に、操作方法を説明せず「今日の目標を確認して、取り組みを記録してください」と伝える。
- 生徒が目標を見つけて記録を保存できたか、かかった時間、助けが必要だったかを記録する。
- 日々の記録時間は、アプリを開いてから実績を保存するまでを測る。任意の写真提出にかかった時間は別に記録する。
- 先生の登録時間は週の課題入力から保存まで、確認時間はその日の進捗を開いてコメントを保存するまでを測る。
- 日々の記録と確認の時間は利用のたびにメモし、週末に平均と最長を集計する。

## 4週間の記録

「計画日」は、その日に1件以上の目標を設定した日です。「記録日」は、計画日のうち、少なくとも1件の実績または完了チェックを保存した日です。

| 週 | 計画日数 | 記録日数 | 記録率 | 生徒の記録時間（平均／最長・分） | 先生の課題登録（分） | 先生の確認（平均／最長・分／日） | 気づいたこと |
|---|---:|---:|---:|---:|---:|---:|---|
| 1週目 |  |  |  |  |  |  |  |
| 2週目 |  |  |  |  |  |  |  |
| 3週目 |  |  |  |  |  |  |  |
| 4週目 |  |  |  |  |  |  |  |
| 合計・平均 |  |  |  |  |  |  |  |

各週の時間はその週に測った利用時間から平均と最長を記録します。課題登録時間は週1回の所要時間です。記録率は **記録日数 ÷ 計画日数 × 100** で計算し、4週間の合計が **70%以上** を目標とします。計画日が0日の週は記録率を計算せず、理由をメモします。

## 4週間後の判定

- 生徒の記録時間：平均3分以内を達成／未達
- 計画日の記録率：70%以上を達成／未達（　　　　%）
- 先生の週課題登録：3分以内を達成／未達
- 先生の進捗確認とコメント：平均1日5分以内を達成／未達
- 説明なしで初回利用：達成／未達
- 続けるために最初に直すこと：

未達の項目があれば、利用者が迷った場所や時間がかかった操作を先に直します。ポイント、ランキング、通知などの機能追加は、試用結果から必要性が確認できた場合にだけ検討します。
