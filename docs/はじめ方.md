# 宿題ノートのはじめ方

先生と生徒が1対1で使うための、セットアップから公開後の確認までの手順です。Firebase にデータを保存し、先生用と生徒用の専用 URL をそれぞれ発行します。現在のアプリに写真提出機能はありません。

## 先に用意するもの

- このプロジェクト一式
- Node.js と npm
- Firebase / Google アカウント
- GitHub アカウント（Vercel に公開する場合）
- Vercel アカウント（公開する場合）

## 1. Firebase プロジェクトを作る

1. [Firebase Console](https://console.firebase.google.com/) を開き、「プロジェクトを追加」から新規プロジェクトを作ります。
2. プロジェクトを開き、Build → Firestore Database → Create database を選びます。
3. 本番モードを選び、利用者に近いロケーションを選択します。ロケーションは後から簡単に変更できないため、実際に使う地域に合わせます。
4. Firestore の「ルール」画面で次を設定して公開します。

   ```text
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /{document=**} {
         allow read, write: if false;
       }
     }
   }
   ```

   ブラウザーから Firestore を直接読めないようにする設定です。アプリはサーバー側の Firebase Admin SDK を使ってアクセスします。Admin SDK は Firestore ルールを迂回するため、サーバーの秘密鍵を公開しないことが重要です。

## 2. Firebase のサーバー用認証情報を用意する

1. Firebase の Project settings（歯車）→ Service accounts を開きます。
2. Firebase Admin SDK のサービスアカウントを確認し、「Generate new private key」から JSON をダウンロードします。
3. ダウンロードした JSON から次の3項目を使います。
   - `project_id` → `FIREBASE_PROJECT_ID`
   - `client_email` → `FIREBASE_CLIENT_EMAIL`
   - `private_key` → `FIREBASE_PRIVATE_KEY`
4. JSON ファイルは Git に追加しないでください。`.env.local` に値を移した後も、JSON は安全な場所に保管し、不要なら安全に削除します。

この鍵は Firebase プロジェクトを操作できる秘密情報です。チャット、メール、公開リポジトリ、スクリーンショットには載せないでください。[Firebase Admin SDK の公式手順](https://firebase.google.com/docs/admin/setup)

## 3. 先生・生徒用のトークンを作る

PowerShell を開き、次のコマンドを2回実行します。出力された2つの値は別々に控えます。

```powershell
node -e "console.log(require('node:crypto').randomBytes(32).toString('base64url'))"
```

1つ目を先生用、2つ目を生徒用にします。トークンはログインパスワードの代わりです。URL を知っている人は画面を開けるため、それぞれ本人にだけ共有してください。紛失時はトークンを作り直して、環境変数を更新し、再起動または再デプロイします。

## 4. ローカル環境を設定する

1. PowerShell でプロジェクトのフォルダーに移動します。

   ```powershell
   cd C:\Users\Admin\project\homework-app
   ```

2. `.env.local` という名前のファイルをプロジェクト直下に作ります（`package.json` と同じ階層）。
3. 以下を貼り付け、`=` の右側を自分の値に置き換えます。

   ```env
   TEACHER_TOKEN=生成した先生用トークン
   STUDENT_TOKEN=生成した生徒用トークン
   FIREBASE_PROJECT_ID=JSONのproject_id
   FIREBASE_CLIENT_EMAIL=JSONのclient_email
   FIREBASE_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\nJSONの秘密鍵本文\n-----END PRIVATE KEY-----\n"
   ```

   `FIREBASE_PRIVATE_KEY` は JSON の `private_key` 全体を貼り付けます。引用符を残し、改行は実際の改行ではなく `\n` で表します。`...` のままでは動きません。変数名に `NEXT_PUBLIC_` を付けないでください。

4. `.env.local` が Git に追加されていないことを確認します。

   ```powershell
   git status --short
   ```

   `.env.local` が一覧に出る場合は、コミット・共有せず `.gitignore` の設定を確認してください。

## 5. 起動して動作を確認する

```powershell
npm install
npm run dev
```

ターミナルに表示されるローカル URL（通常は `http://localhost:3000`）をブラウザーで開きます。

- 先生用: `http://localhost:3000/t/先生用トークン`
- 生徒用: `http://localhost:3000/s/生徒用トークン`

最低限、次を確認します。

1. 先生画面で宿題を登録する。
2. 生徒画面で登録内容が見えることを確認し、完了にする。
3. 先生画面で完了が反映され、確認操作やコメントができることを確認する。
4. ページを再読み込みしても内容が残っていることを確認する。
5. トークンを一部変えた URL では画面を使えないことを確認する。

ローカルサーバーを止めるときは、起動した PowerShell で `Ctrl+C` を押します。環境変数を変更したらサーバーを再起動してください。

## 6. Vercel に公開する

1. プロジェクトを GitHub の非公開リポジトリに push します。`.env.local` やサービスアカウント JSON は push しません。
2. [Vercel](https://vercel.com/) で GitHub リポジトリを Import し、初期設定のまま Deploy します。
3. Vercel の Project → Settings → Environment Variables に、以下の5項目を登録します。
   - `TEACHER_TOKEN`
   - `STUDENT_TOKEN`
   - `FIREBASE_PROJECT_ID`
   - `FIREBASE_CLIENT_EMAIL`
   - `FIREBASE_PRIVATE_KEY`
4. 使う環境（通常は Production。確認用には Preview も）を選んで保存します。
5. Deployments から最新デプロイを再実行します。環境変数は登録しただけでは既存デプロイに反映されません。
6. 公開 URL で先生用・生徒用 URL を開き、ローカルと同じ登録・完了・再読み込み確認を行います。

Vercel は環境変数を環境ごとに設定できます。値を変更した後は新しいデプロイが必要です。[Vercel 環境変数の公式説明](https://vercel.com/docs/environment-variables)

## 7. 利用者に URL を渡す

公開できたら、先生には `/t/先生用トークン` の URL、生徒には `/s/生徒用トークン` の URL を個別に渡します。トークン付き URL は本人確認の鍵なので、共有グループや公開ページに掲載しないでください。ブラウザーのお気に入りに登録すると、次回から簡単に開けます。

## データの保存先

Firestore の `days` コレクションに、`YYYY-MM-DD` をドキュメント ID として日ごとの宿題・提出状態を保存します。読み書きはサーバー API 経由です。写真ストレージは使いません。Firestore のサーバー SDK の概要は[公式クイックスタート](https://firebase.google.com/docs/firestore/quickstart-server)を参照してください。

## よくあるつまずき

- **「Firebase が設定されていない」などのエラー**: 5つの環境変数名、値、`.env.local` の場所を確認し、開発サーバーを再起動します。
- **秘密鍵の認証エラー**: JSON の `private_key` 全体を貼ったか、引用符と `\n` を保ったかを確認します。余分な引用符や `...` があると失敗します。
- **先生／生徒ページが開けない**: URL の `/t/` と `/s/`、トークンの取り違えや前後の空白を確認します。トークンは32文字以上である必要があります。
- **デプロイ後だけ動かない**: Vercel の Production に環境変数が登録されているか確認し、再デプロイします。
- **ブラウザーから Firestore を読めない**: 直接接続は意図的に拒否しています。アプリの画面から操作してください。

## 現在の範囲

先生と生徒が1対1で使う構成です。宿題登録、完了、履歴、確認、コメントを扱います。写真提出、複数生徒のアカウント管理、通知機能は含みません。実際のデータを保存するには Firebase の設定が必須です。
